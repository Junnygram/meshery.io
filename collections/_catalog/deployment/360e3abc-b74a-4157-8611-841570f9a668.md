patternInfo: |
  Lattice is infrastructure as design across Kubernetes and AWS operators you
  already run. An API Deployment talks to an ACK-managed RDS instance and an
  ACK-managed S3 bucket. An ACK IAM Role is bound to the API ServiceAccount
  with IRSA. External Secrets copies the RDS password into the app namespace.
  Gateway API is the only public edge. Kubernetes resources and cloud
  resources live in one graph.
patternCaveats: |
  ACK controllers for RDS, S3, and IAM must be installed. Replace ACCOUNT_ID,
  subnet IDs, security group IDs, and the DB subnet group. Subnet IDs in this
  design are placeholders — do not publish identifiers from a real account.
