patternInfo: |
  Northstar is an internal developer platform drawn as infrastructure as design.
  Backstage is the catalog and scaffolding UI. Argo CD ApplicationSets generate
  one Application per environment from the same Git repo. External Secrets
  injects Git and OCI credentials so those never live in the design. Staging
  and production are separate namespaces with their own HTTPRoutes: one design,
  many targets.
patternCaveats: |
  Replace the Backstage image with the one your org builds. Point the
  ApplicationSet at a real repo. Argo CD is assumed already installed in
  argocd; this design is the platform layer on top, not a Helm dump of the
  Argo control plane.
