patternInfo: |
  Thrift is a Karpenter compute plane for EKS that prefers Spot, falls back
  to on-demand, and consolidates empty or underutilized nodes. Two NodePools
  split general workloads from interruptible burst. EC2NodeClass pins AL2023,
  encrypted gp3, and discovery tags. A sample payments Deployment uses
  topology spread and a PodDisruptionBudget so consolidation never takes the
  last replica.
patternCaveats: |
  Replace ACCOUNT_ID, the IAM node role, and karpenter.sh/discovery tags with
  your cluster name. Spot interruption is expected. Do not run this alongside
  Cluster Autoscaler on the same nodes.
