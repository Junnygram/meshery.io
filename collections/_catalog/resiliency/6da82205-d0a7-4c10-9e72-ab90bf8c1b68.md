patternInfo: |
  Harborlight is a production PostgreSQL data service on Kubernetes using the
  CloudNativePG operator. Three instances stream-replicate across zones. A
  PgBouncer Pooler sits in front so application connections survive failovers.
  ScheduledBackup ships WAL and base backups to S3 with a 30-day retention
  policy. NetworkPolicy allows 5432 only from labeled application namespaces.
  PodMonitor feeds Postgres metrics to Prometheus.
patternCaveats: |
  The CloudNativePG operator must already be installed. Replace the S3 bucket,
  IAM role, and storage class. Three instances need three zones. Pooler
  credentials are generated by the operator — do not commit application
  passwords into this design.
